# 🎨 Random Hex Color Generator

## 📌 About
This is a simple Python project that generates random HEX color codes using loops and the random module. It is a beginner-friendly project to practice Python fundamentals.

---

## ⚙️ Features
- Generates random HEX color codes
- Uses Python's `random` module
- Uses loops and string manipulation
- Can generate multiple colors at once

---

## Where can this be used?
## 📌 Use Cases
- Useful in web development for generating random color themes for UI design
- Can be used for testing frontend layouts that require dynamic colors
- Helpful in design inspiration and color palette generation
- Great beginner project for learning Python basics

  
## 🚀 How to run

1. Make sure Python is installed on your system  
2. Download or clone this repository  
3. Open terminal / command prompt in the project folder  
4. Run the file using:

```bash
python Project_1.py
```
